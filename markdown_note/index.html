Markdown笔记

摘要

Markdown 笔记，主体内容为《了不起的Markdown》一书的学习笔记。

1. 前言

《了不起的Markdown》一书中介绍了 Markdown 的语法，本文根据书中推荐写法整理出一套适合自己的 Markdown 笔记规范。

2. 正文

2.1 基础语法

2.1.1 字体

2.1.1.1 标题

Markdown 使用 # 符号来表示标题，# 的数量表示标题的级别。

语法

  1. 在行首插入 # 可标记出标题。
  2. # 的个数表示了标题的等级。
  3. Markdown 中最多只支持前六级标题。

建议

  1. 在#后加一个空格。
  2. 标题的前后都要空1行。
  3. 标题写在一行开头。
  4. 结尾不要有空格或标点符号。
  5. 标题的内容要简洁明了。

示例

2.1.1.2 粗体和斜体

语法

  1. 使用 ** 将文本包裹起来可以实现粗体效果。
  2. 使用 * 将文本包裹起来可以实现斜体效果。

建议

  1. 粗体和斜体的标记符号前后都不要有空格。

示例

2.1.2 段落和换行

2.1.2.1 空行

语法

  1. 如果行与行之间没有空行，则会被视为同一段落。
  2. 如果行与行之间有空行，则会被视为不同的段落。
  3. 空行是指行内什么都没有，或者只有空格和制表符。
  4. 如果想在段内换行，则需要在上一行的结尾插入两个以上的空格然后按回车键。

建议

  1. 当超过80个字符后进行换行。
  2. 在一句话结束（。或!或?）之后换行。
  3. 当URL较长时换行。
2.1.2.2 列表

语法

  1. 使用 - 表示无序列表。
  2. 使用数字加 num. 表示有序列表。
  3. 列表可以互相嵌套，嵌套时需要在子列表项前加四空格或一个制表符。

建议

  1. 每个列表项只有一行，则列表项的标记符号后要加一个空格。
  2. 数字、字符、符号列表使用英文半角句号，句号后加空格。

2.1.4.1 插入链接

语法

2.1.5.2 代码块

语法

  1. 使用三个的 ` 可以创建代码块。

建议

  1. 代码块前后都要有空行。
  2. 代码块的内容要缩进四个空格或一个制表符。
  3. 简单代码片段，用四个空格缩进即可，而不用使用 ```。
  4. shell 有输出时用 $ 区分命令和输出，没输出时不用 $。
  5. 建议使用围栏代码块。

2.2.3 自动链接

语法

  1. 使用 <链接地址> 可以创建自动链接。
  2. 自动链接只识别以 www 或 http:// 开头的URL地址。
  3. 不想要自动链接的URL地址，可以使用 ` 将其包裹起来。

2.2.4 表格

语法

  1. 使用 | 分隔表格的列。
  2. 使用 - 分隔表头和表格内容。
  3. 表格的每一行都需要以 | 开头和结尾。
  4. 对齐方式可以通过在 - 前添加 : 来设置：
    • :--- 表示左对齐
    • :---: 表示居中对齐
    • ---: 表示右对齐
  5. 块级元素（如代码块、引用等）不能直接放在表格内。

建议

  1. 表格的列数可以不一致，但建议保持一致性。

示例

左对齐 居中对齐 右对齐
内容1 内容2 内容3
内容4 内容5 内容6

2.2.5 任务列表

语法

  1. 使用 - [ ] 创建未完成的任务列表项。
  2. 使用 - [x] 创建已完成的任务列表项。
  3. 任务列表项可以嵌套，嵌套时需要在子列表项前加两个空格或一个制表符。
  4. 任务列表项的标记符号前后都不要有空格。
  5. 任务列表项的内容可以包含其他Markdown语法，如链接、图片等。

示例

  • [ ] 任务1
  • [X] 任务2
    • [X] 子任务1
    • [ ] 子任务2
