ZYNQ-VIP使用笔记

ZYNQ UltraScale+ PS-E VIP 官方文档（PDF）

1. 简介

ZYNQ VIP（Verification IP）是 Xilinx 针对 Zynq 系列器件推出的验证 IP，内置多种主流总线和外设协议接口，极大简化了FPGA/SoC设计中的系统级验证工作。ZYNQ VIP 支持 AXI、AXI4-Lite、AXI4-Stream、PCIe 等协议，便于设计者快速集成和验证通信接口。

实际应用中，ZYNQ VIP 常用于 AXI 主机读写、DDR 初始化等场景。

2. 版本选择

ZYNQ VIP 主要分为 Zynq-7000 和 Zynq UltraScale+ 两大类，不同版本支持的协议和功能有所区别，需根据目标芯片选择合适版本：

  • Zynq-7000 VIP：适用于 Zynq-7000 系列，支持 AXI4、AXI4-Lite、AXI4-Stream 等协议。
  • Zynq UltraScale+ VIP：适用于 Zynq UltraScale+ 系列，支持更高性能协议（如 PCIe Gen3、SATA 等）。

相关文档参考：

3. 地址映射与使用注意事项

  • PS DDR 前部地址不可用，部分区域被程序等占用。

  • AXI DDR 地址映射时，部分地址被固定设备占用。

  • fpga_soft_reset

    • 作用：对 PL（可编程逻辑）发起软复位。
    • 输入参数 [3:0] reset_ctrl：4 位输入，指示对 PL 哪些复位通道进行复位（与 PS 侧的 FPGA_RST_CTRL 寄存器一致）。
    • 无输出。

  • por_srstb_reset

    • 作用：对 VIP 发起强制复位（Power-On Reset），是仿真环境下必须的全局复位。
    • 输入参数 por_reset_ctrl：1 位输入，控制 VIP 的复位。
    • 无输出。

  • por_srstb_reset API 必须在任何其他 API 调用或任何 AXI 读写操作前执行，确保 VIP 处于初始复位状态。

  • 示例代码展示了典型的复位流程：

    1. 首先拉高 por_srstb_reset，进入复位状态。
    2. 延时后拉低，释放复位。
    3. 调用 fpga_soft_reset，对 PL 进行软复位。
    4. 保证软复位信号宽度（最少16个时钟周期）。
    5. 再次拉高 por_srstb_reset 并释放 fpga_soft_reset，完成整个复位流程。

por_srstb_reset 和 fpga_soft_reset 这两个 API 都是高电平有效复位（active high reset）。

总结：
这两个 API 是 ZYNQ VIP 仿真环境初始化和后续操作的基础，必须严格按照流程调用，确保仿真和协议操作的正确性。

5.4 数据格式

小端格式（Little Endian）

  • 数据按字节顺序存储，低地址存储低有效字节。
  • 例如，32 位数据 0x12345678 的存储方式如下：
    • 地址 0x00：0x78
    • 地址 0x01：0x56
    • 地址 0x02：0x34
    • 地址 0x03：0x12

大端格式（Big Endian）

  • 数据按字节顺序存储，高地址存储低有效字节。
  • 例如，32 位数据 0x12345678 的存储方式如下：
    • 地址 0x00：0x12
    • 地址 0x01：0x34
    • 地址 0x02：0x56
    • 地址 0x03：0x78

ZYNQ 平台数据格式说明

  • PS端（处理系统）默认采用小端格式，无论是数据存储（如 PS DDR）还是数据传输，均为小端。
  • PS 与 PL 通信 时，AXI 总线数据传输也采用小端格式。
  • AXI interconnect：
    • PS 侧接口（AXI HPM/HP）最大支持 128 位数据宽度。
    • PL 侧接口最大支持 1024 位数据宽度。
    • 当 PL 端数据宽度大于 PS 端时，AXI interconnect 会自动进行数据宽度转换，转换逻辑为小端逻辑，即低位数据存放在低地址。
  • PL 端 通过 AXI 总线读写 PL DDR 时，数据同样以小端格式存放。

常见数据流向与大小端关系

步骤 数据流向 说明 格式
1 外部设备（以太网、SD卡） 数据输入到 PS 大端*
2 PS 处理 PS 端处理数据 小端
3 PS DDR 数据存储到 PS DDR 小端
4 PS 处理 PS 端再次处理数据 小端
5 AXI 总线 传输到 PL 小端
6 PL 处理 PL 端处理数据 大端*
7 PL DDR 数据存储到 PL DDR 大端*
8 PL 处理 PL 端再次处理数据 大端*
9 AXI 总线 传回 PS 小端
10 PS 处理 PS 端处理返回数据 小端
11 PS DDR 数据再次存储到 PS DDR 小端
12 PS 处理 PS 端最终处理 小端
13 外部设备 数据输出到外部设备 大端*

注：PL 端内部处理和 DDR 存储格式可根据实际设计选择大端或小端，但与 AXI 总线交互时需注意格式转换。AXI interconnect 进行数据宽度转换时，采用类似小端的逻辑（低位在低地址）。
