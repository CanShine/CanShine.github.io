DDR与MIG笔记

1 DDR4 SDRAM（MIG）简介

MIG(Memory Interface Generator)是Xilinx提供的一种用于生成内存接口的IP核，支持多种类型的内存，包括DDR、DDR2、DDR3、DDR4等。MIG可以帮助设计者快速配置和集成内存接口，简化设计流程，提高系统性能。

2 MIG基本配置

MIG的基本配置包括以下几个方面：

  • Clocking
    • Memory Device Interface Speed(ps)：指DDR的工作频率，单位为皮秒(ps)，例如1000ps表示DDR工作频率为1000MHz。
    • PHY to controller clock frequency ratio：指MIG内部PHY与控制器之间的时钟频率比率，例如4:1表示PHY的时钟频率是控制器的4倍。由于DDR采用双边沿采样，所以数据频率比率为8:1。
    • Reference Input Clock Speed(ps)：指MIG参考时钟的频率，单位为皮秒(ps)，例如3334ps表示参考时钟频率为300MHz。如果工作频率>666MHz ，参考时钟固定为300MHz/400MHz，其他工作频率固定为200MHz，MIG内部会分频和倍频至工作时钟
  • Controller Options
    • Memory Part：指所使用的DDR芯片型号，例如MT40A1G16RC-062E表示使用Micron公司的DDR4芯片，容量为1GB，数据宽度为16bit。
    • Data Width(bits)：指MIG与DDR之间的数据位宽，例如64bits表示MIG与DDR之间的数据宽度为64位，4片16bits位宽的DDR组成64bits位宽，与硬件平台有关。

3 MIG相关AXI配置

AXI相关配置包括以下几个方面：

Data Width(bits)：指AXI接口的数据位宽，例如512bits表示AXI接口的数据宽度为512位。
Address Width(bits)：指AXI接口的地址位宽，例如32bits表示AXI接口的地址宽度为32位。
