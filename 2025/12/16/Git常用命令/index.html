Git常用命令

本文总结 Git 日常开发中最常用的命令及其推荐使用流程，适用于个人开发与基本协作场景。

一、Git 常用命令速查

命令 作用 影响区域 是否联网
status 查看当前仓库状态 只读 ❌
add 工作区 → 暂存区 暂存区 ❌
commit 暂存区 → 本地仓库 本地仓库 ❌
fetch 获取远程更新（不合并） 远程跟踪分支 ✅
pull 获取并合并远程更新 本地分支 ✅
push 推送本地提交到远程 远程仓库 ✅

二、最常见的日常开发流程

适用于个人开发或小规模协作，是最常用、最推荐的流程。

步骤 目的说明
status 查看本地修改内容
add 选择要提交的改动
commit 将改动保存到本地仓库
pull 同步远程更新，避免冲突
push 将本地提交推送到远程

三、新电脑 / 新环境的首次配置流程

在新环境中使用 Git 前，需要完成用户信息配置。

命令 作用
user.name / user.email 标识提交者身份
clone 克隆远程仓库到本地

四、git fetch 与 git status 的配合使用

推荐顺序

使用说明

  • git fetch：从远程仓库更新 远程跟踪分支（如 origin/main）
  • git status：对比 本地分支 与 本地记录的远程状态

⚠️ git status 不会主动访问远程仓库，只有在执行 fetch 或 pull 后，远程状态才是最新的。

五、使用建议总结

场景 推荐操作
查看本地改动 git status
判断是否落后远程 git fetch → git status
日常提交代码 status → add → commit → pull → push
谨慎合并前检查 fetch → status → log

六、关键理解（核心一句话）

Git 不会自动联网
所有远程信息都是本地缓存，需要 fetch 或 pull 才会更新

工程效率 > Git
